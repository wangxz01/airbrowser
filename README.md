# Air 浏览器

为 MatePad Air 12 / HarmonyOS 6.1 设计的原生平板浏览器。使用 ArkTS、ArkUI 和系统 ArkWeb；顶部为 48 vp 单行工具栏，左侧为可折叠标签栏。

这是独立项目：包名 `com.adam.airbrowser`、应用名 **Air 浏览器**、Preferences 名 `air_browser_v1`。与同级 StudyPad 工程分别构建、安装和保存数据。没有复制 StudyPad 的签名配置、证书或私钥。

## 已实现

- HTTP/HTTPS 网址、关键词搜索、网页前进后退、刷新/停止；地址栏支持触控提交和实体键盘回车。
- 左侧多标签、新建、关闭、重新打开误关网页、长按移动顺序、折叠图标栏。窄窗口自动收窄侧栏，展开宽度可在设置中调整。
- 浏览过程中切换标签和调整布局复用 Web 组件；恢复会话时按需加载标签。最多 24 个标签，可手动休眠无声音的后台标签。
- 网站通过用户点击打开的新窗口成为独立标签；默认阻止自动弹窗和跳转外部 App。
- 当前网页收藏、收藏夹、最近 300 条去重历史、重启后恢复标签地址和选中的标签。
- 默认系统返回只收起地址编辑、对话框、菜单或视频全屏，不关闭标签、不操作网页历史；顶部箭头负责网页历史。设置中可开启系统返回也后退网页。
- ArkWeb 视频全屏回调，隐藏浏览器工具栏和侧栏；退出全屏恢复原布局。平板同时请求隐藏系统状态栏及导航栏。
- B 站官网与官方登录入口、按主机名记忆“请求电脑版网页”、当前标签静音。
- 网站 Cookie 由 ArkWeb 管理，页面加载完成、后台和手动保存时请求落盘。正常关闭标签和清理资源缓存不清除 Cookie 或网站存储。
- 页面失败提示、证书错误拦截、网站 alert/confirm/prompt 对话框、浅色与深色资源。

## 打开与构建

首次克隆后先创建本地构建配置，再在 DevEco Studio 中通过 **Open** 打开此目录本身，不要将 `entry` 导入其他工程。

```sh
cp build-profile.example.json5 build-profile.json5
```

本地已有该配置时不要覆盖，签名信息仅保存在这个被 Git 忽略的文件中。

```sh
npm run doctor
npm run check
npm run build
```

本机默认使用 `/Applications/DevEco-Studio.app` 自带的 Node、OHPM、Hvigor、SDK 和 Java。IDE 在其他位置时设置 `AIR_BROWSER_DEVECO_PATH`。测试需要 Node 22.13+（使用内置 TypeScript 类型擦除）。没有第三方运行时依赖。

构建脚本会在缺少本地配置时从 `build-profile.example.json5` 生成 `build-profile.json5`。后者被 Git 忽略，供本项目独立签名使用。

未签名安装包：`entry/build/default/outputs/default/AirBrowser-unsigned.hap`。它可用于允许未签名调试的模拟器，不能直接安装到普通真机。本地 `artifacts/` 用于保存测试截图和日志，不上传到 GitHub。配置签名后，签名包为同目录下的 `AirBrowser.hap`。

本次使用 HarmonyOS SDK 26.0.0.105 编译，兼容和目标版本均为 API 12。源码未要求平板安装 SDK 26；本机较新的编译工具与应用最低运行版本是不同概念。

## 在平板运行

1. 在 DevEco Studio 打开本工程，连接并授权平板 USB 调试。
2. 为包名 **com.adam.airbrowser** 配置本项目的自动调试签名。使用自己的华为开发者账号完成 IDE 授权。
3. 选择平板后运行。不要把包名改成其他已有应用的包名，也不要复制其他项目的 provisioning profile；否则可能安装失败或覆盖其他应用。
4. 按 [设备验收清单](docs/device-validation.md) 验证系统返回、B 站登录、清晰度与播放稳定性。

本项目已配置独立调试签名并验证过真机安装。签名资料不应提交 Git。按用户最新要求，后续运行测试仅在 HarmonyOS 6.1.0 平板模拟器进行，不操作真机或其他类型模拟器。

## 登录保持的边界

Cookie 和 localStorage 保存在系统分配给 **Air 浏览器** 的独立应用数据中。应用不提取、记录、导出密码或 Cookie，也不与系统浏览器、B 站客户端或 StudyPad 共享登录。

浏览器会保存网站允许持久化的 Cookie；网站主动失效、会话 Cookie、账号风控、用户退出登录、卸载或清除应用数据仍可能要求重新登录。不能保证永久登录。模拟器测试使用无账号的本地测试 Cookie，不等同于验证了 B 站账号的有效期。

## 当前范围

- 会话恢复保存地址、标题和选中的标签；进程重启后不恢复 Web 引擎内的前进/后退栈、未提交表单、滚动位置和视频进度。
- 手动休眠会卸载无声音的后台网页，包括静音视频和未提交表单；操作前会提示。正在发声的标签保留。应用处于系统后台时持续播放、画中画尚未实现。
- “电脑版网页”修改当前站点的 User-Agent 请求，沿用本机渲染引擎版本；网站是否提供桌面布局由网站决定。尚未给 B 站注入自定义排版或替换播放器。
- 文件下载、文件上传、网页摄像头/麦克风、密码管理、扩展、云同步、默认浏览器注册尚未实现。网页相机/麦克风申请当前会被拒绝并提示。
- 网站的网页播放器、登录权限和清晰度由原站决定。没有提取视频地址、调用非公开视频接口或绕过会员限制。

## 当前设备与内核策略

当前布局保留系统状态栏，48 vp 浏览器工具栏位于其下方。视频全屏时隐藏系统栏，退出后恢复。底部仅延伸背景，控件保留安全区。验证记录见 [验证记录](docs/verification.md)。

发行配置只声明 `tablet`。独立 Chromium 内核方案暂停，继续使用系统 ArkWeb。后续只在用户指定的 HarmonyOS 6.1.0 平板模拟器上做运行测试。当前版本已完成该模拟器的安装启动、基础交互和 B 站播放验证，见 [平板验收记录](docs/tablet61-validation.md)。

标签页已接入系统网站图标回调及页面结束时的缓存图标读取；声音和休眠显示为附加角标。未提供图标的网站使用通用图标，新标签页使用应用图标。图标目前仅在内存保存，恢复后尚未加载的标签会先显示通用图标。已在新平板模拟器确认 B 站图标能正常显示，展开和折叠侧栏均可见。

网页缩放入口：打开网页后，点击右上角“⋯ → 网页缩放”，使用 − / + 调整 50%–200%，或点击“重置”恢复 100%。倍率按标签页独立生效，刷新保留，应用重启后恢复默认。

网页内查找：打开网页后，点击右上角“⋯ → 网页内查找”。输入关键词后高亮匹配文字，显示当前项/总数；使用上下箭头跳转，点 × 或系统返回关闭。切换标签或导航到新页面会关闭查找。
