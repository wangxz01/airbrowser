# HarmonyOS 6.1 平板验收

日期：2026-09-21。源码基线：`49bf078`。本轮只测试并更新文档，没有修改浏览器代码。

## 环境

- 模拟器配置：MatePad Air 12，HarmonyOS 6.1.0(23)，API 23。
- HDC target：`127.0.0.1:5555`；运行前核验 `const.product.devicetype=tablet`，`const.ohos.fullname=OpenHarmony-6.1.0.115`。
- 屏幕：2800 × 1840，density 360；横屏。
- 安装当前 `AirBrowser-unsigned.hap`，包名 `com.adam.airbrowser`，EntryAbility 启动成功。模拟器允许未签名调试；这不能证明真机签名有效。
- 没有操作物理平板或旧 2in1/手机模拟器，没有迁移 Chromium。

## 14 项基础断言

使用 `tests/fixture-server.mjs` 提供的本地 A/B 页面，以及 `tests/native-ui.py` 通过原生 UI 操作测试；结果保存于本地 `artifacts/tablet61-smoke.json`。

1. 默认系统返回留在 B 页面。
2. 顶部后退从 B 回到 A。
3. 顶部前进从 A 回到 B。
4. 测试持久 Cookie 写入成功。
5. 网页新窗口链接新建标签，并共享本应用 Cookie 和 localStorage。
6. 新建标签按钮紧随最后一个标签。
7. 系统返回关闭网页原生 alert 对话框。
8. 系统返回关闭原生更多菜单。
9. 设置半模态页面可打开和返回关闭。
10. 历史半模态页面可打开和返回关闭。
11. 收藏操作后的页面出现在原生收藏夹。
12. 本地视频全屏隐藏顶部与侧栏，系统返回恢复原页面。
13. 手动保存标签与网站状态出现成功提示。
14. force-stop 后启动，恢复两个标签、当前页、测试持久 Cookie 与 localStorage。

测试 Cookie 是固定无敏感值标记，没有使用用户账号。重启指应用进程重启，不是模拟器系统重启；本地视频这一项验证全屏交互，不是解码性能。

## B 站与外观

| 项目 | 观察结果 |
| --- | --- |
| 网站加载 | 公共视频 `https://www.bilibili.com/video/BV1mktR6gEd3/` 标题与网页正常显示 |
| favicon | 标签左侧显示 B 站蓝色电视图标；展开、折叠侧栏均可见；无图标测试页显示通用图标 |
| 视频播放 | 未登录、播放器静音；显示实际课程画面，连续采样从 0:01:27 推进到 0:01:32，后续截图为 0:01:37、0:01:43 |

| 侧栏 | 收起后 Web 区域左边界由 495 px 变为 117 px，网页重新排版 |

首次连续采样曾在 0:01:01 没有变化，随后检查发现网站登录弹窗。关闭提示并点击播放后，播放时间继续推进。此次没有登录账号；不能据此断言登录弹窗与那次暂停的唯一因果关系，也不能承诺未登录播放不会再次中断。
