# 平板验收清单

当前运行测试仅在用户指定的 HarmonyOS 6.1.0 平板模拟器完成，不部署或操作真机及其他模拟器。以下涉及真实账号、耗电、温度和实体键盘的项目留待用户以后授权真机验证；模拟器结果不能代替这些指标。应用包名为 `com.adam.airbrowser`。

## 返回与布局

1. 打开 A 页面，再进入 B 页面。点击顶部后退返回 A；前进返回 B。
2. 默认设置下，从 B 页面使用系统侧滑返回：应保留 B 页面和标签。
3. 在地址栏编辑时返回，应先结束输入；菜单打开时返回，应只关闭菜单。
4. 播放视频并进入全屏，再返回：应只退出全屏，视频页面和标签不变。
5. 反复横竖屏切换、系统分屏、折叠侧栏。网页组件不应因这些布局操作被重新创建。
6. 调整侧栏宽度，确认工具栏始终单行、触控目标易点按；系统状态栏区域没有遮住地址栏。
7. 用实体键盘输入网址并按回车；验证软键盘“前往”和编辑时出现的箭头也能提交。

## 登录与存储

1. 从 B 站官方登录页自行登录，不向开发者或助手提供验证码与 Cookie。
2. 回到 B 站官网，确认账号状态；新开另一个 B 站标签应共享本应用的登录。
3. 进入设置，点击“保存标签与网站状态”；关闭再打开应用、重启平板、隔天再打开分别检查。
4. 仅清理资源缓存后检查账号仍保持；不点击网站退出、不清除应用数据。
5. 若掉登录，区分网站返回失效与本地持久化失败；检查时只记录 Cookie 类型/是否存在等诊断信息，不输出值。
6. 验证标签、选中项、收藏与电脑版站点偏好在重启后保留。

## B 站播放

1. 在同一网络、同一视频、同一清晰度下与现用浏览器比较。
2. 播放至少 20 分钟，记录清晰度、弹幕开关、卡顿、音画同步、发热及耗电。
3. 拖动进度、切换清晰度、全屏往返 10 次、旋转屏幕各检查一遍。
4. 先开 3 个常用网页，再打开视频；切换标签后返回，检查播放器状态。
5. 分别比较默认模式和“请求电脑版网页”的布局、清晰度入口、登录及弹幕。
6. 画中画和系统后台持续播放当前不属于已完成能力。

## 本地测试网页复现

仅在开发机器和模拟器使用。先在 `artifacts/test-video.mp4` 放入自制测试视频，或用 ffmpeg 生成：

```sh
mkdir -p artifacts
ffmpeg -f lavfi -i testsrc2=size=640x360:rate=24 -t 8 -c:v libx264 -pix_fmt yuv420p -movflags +faststart artifacts/test-video.mp4
node tests/fixture-server.mjs
```

使用 DevEco 自带 HDC 为明确指定的模拟器设置 `rport tcp:18765 tcp:18765`，然后在 Air 浏览器中打开 `http://127.0.0.1:18765/a`。

测试页可验证普通导航、SPA 导航、新标签、持久 Cookie、localStorage、网站弹窗和视频全屏。检查结束后停止测试服务器并移除此端口映射。不要把测试服务器用于存放真实账号凭据。
